## 📝 Deskripsi Kode
Sistem perbankan sederhana ini terdiri dari 4 file kelas:
1. `Account.java`: Mengelola saldo dan logika transaksi (deposit, withdraw, cek saldo).
2. `Customer.java`: Mengelola data nasabah dan menyimpan daftar akun menggunakan **ArrayList**.
3. `Bank.java`: Mengelola kumpulan daftar nasabah di bank menggunakan **Array** standar.
4. `Main.java`: Berisi menu interaktif ATM sederhana bergaya terminal.
